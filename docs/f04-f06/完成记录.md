## 完成内容

### F04 问题列表、筛选与搜索

- 课程内问题列表支持分页、关键词、标签、最新/活跃/热度/相关度排序、未解决（按当前后端的零回答语义）和有悬赏筛选。
- 查询条件写入 URL，从详情返回时保留课程、关键词、筛选及页码。
- 查询变化时取消旧请求，防止旧结果覆盖新条件。
- 区分课程无问题与搜索无结果；提供清空筛选和提问入口。
- 搜索高亮用 React 文本节点和 `mark` 渲染，不注入搜索 HTML。

### F05 提问与编辑

- 课程必选且只能选择本人已加入课程；支持标题、Markdown 正文、标签、编辑/预览。
- 前端校验标题 10-150 字、正文 20-30000 字、标签 1-5 个以及重复标签。
- 提交期间只禁用相关表单控件；失败保留输入；成功后进入问题详情。
- 新增 `/questions/:id/edit` 编辑路由，加载现有内容并校验 `canEdit`，课程不可修改。
- 浏览器关闭、刷新和站内跳转均提示未保存内容。
- 标题/正文/课程变化后以 400ms 防抖重新查询相似问题；旧请求取消，推荐失败不阻塞发布。

### F06 问题详情、人工回答与评论

- 展示问题正文、课程、标签、作者、时间、状态、投票，以及按权限显示编辑/删除入口。
- Markdown 正文使用 `react-markdown` 的 `skipHtml` 安全渲染；预览同样不执行 HTML。
- 回答默认按课程回答认证、采纳、票数排序；有来源字段时将 AI 参考单独展示并禁用人工奖励操作。
- 支持回答 Markdown 编辑/预览、提交、编辑、删除，并为删除提供影响说明确认。
- 问题与回答均支持评论及二级回复；失败保留评论输入并在评论区提示。
- 回答与评论按每批 20 条在前端逐步展示；通知锚点可自动展开并定位。
- 写操作按对象分别防重复提交，局部刷新不清空未提交的回答或评论草稿。

## 后端契约限制

- 当前搜索接口的 `unanswered=true` 实现为总回答数为 0，尚不能表达“零人工回答”；前端文案按“未解决”展示，需后端补充人工回答计数字段后才能严格区分。
- 当前回答详情没有正式返回 `source` 和独立 `canDelete` 字段；前端兼容这些字段，缺失时把来源显示为“来源未标记”，删除权限回退到现有 `canEdit`。
- 当前详情接口一次返回全部回答和评论，没有服务端分页参数；本次只做前端分批展示，真正的数据量控制依赖后端增加分页契约。
- 认证接口和权限仍使用现有 `endorsement` / `canManage` 契约；本批没有实现属于 F07 的撤销认证、错误采纳复核等新增能力。
