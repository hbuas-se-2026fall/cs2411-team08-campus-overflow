## 设计决策

- **以测试为规格（红→绿→重构）**：`QuestionTest` / `AnswerTest` / `VoteAndCommentTest` 共 15 条领域用例 + `AnswerAndVoteServiceTest` 4 条编排用例就是现成规格，实现严格贴合，不改断言。
- **不变量在领域层、权限判定入口在应用层**：`actorManagesCourse` 由应用层查询后传入领域方法，领域层保持纯 Java 且不感知 `Actor` 之外的 HTTP/会话细节（FF-1）。
- **采纳单向不可重复**：`accept` 检测到已有采纳抛 `ConflictException`，不提供「换采纳」（换采纳需求由 B04-2 的复核撤销流程满足，且不与本批测试冲突）。
- **投票幂等**：同值重复投票不重发 `VoteCastEvent`，`scoreDelta = 新 − 旧` 保证改票/撤票的分数增量正确。
- **DRY / KISS**：`comment.questionId` 由目标聚合推导，不信任客户端；列表缓存用 cache-aside，写操作统一 `invalidateAll()`。
